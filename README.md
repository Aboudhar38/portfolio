# Kananura Aboudhar — Personal Portfolio

## Project Description
A beginner-friendly, one-page personal portfolio website. It introduces the student, presents skills and practice projects, and provides contact information.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Git and GitHub

## Project Structure
```text
portfolio/
├── index.html
├── styles.css
├── images/
└── README.md
```

## How to Run the Project
1. Download or clone this repository.
2. Open the `portfolio` folder.
3. Open `index.html` in a web browser.

No extra software or JavaScript is required.

## Before Submitting
- Replace `your-email@example.com` with an email address you are comfortable sharing publicly.
- Replace the initials placeholder in the hero section with your own profile photo if you want to use one. Add the image to the `images` folder and include meaningful `alt` text.
- Check that the project descriptions accurately describe your work.
- Test the page on desktop and mobile screen sizes.
